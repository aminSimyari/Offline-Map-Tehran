# Offline Map Tehran

An offline map application for Tehran built with Vue 3, TypeScript, MapLibre GL JS, and PMTiles.

## Technologies

* Vue 3
* TypeScript
* Vite
* MapLibre GL JS
* PMTiles
* Tailwind CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/aminSimyari/Offline-Map-Tehran.git
cd Offline-Map-Tehran
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
